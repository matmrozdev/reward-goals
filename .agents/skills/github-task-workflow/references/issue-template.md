# GitHub issue template

Use the repository's established title pattern:

```text
<type>(<scope>): <imperative description>
```

Use this body structure:

```md
## Description

Describe the outcome and why it is needed.

## Scope

- List the concrete changes included in the task.
- Keep unrelated follow-up work out of scope.

## Acceptance Criteria

- [ ] State observable, verifiable completion conditions.
- [ ] Include relevant validation commands or user-visible behavior.
```

Derive every section from the user's request and verified repository context.
Do not add speculative requirements solely to make the issue appear complete.
