# Expo versioned documentation

Expo has changed. Before writing or modifying mobile code, read the exact Expo
SDK 57 documentation at <https://docs.expo.dev/versions/v57.0.0/>.

Do not substitute documentation for another Expo SDK version. Confirm the
installed Expo version before changing this rule during a future SDK upgrade.
